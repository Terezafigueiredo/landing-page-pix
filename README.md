# 💳 Landing Page PIX – Instituto Rope

Sobre o Projeto

Este projeto surgiu a partir da minha atuação como Social Media no Instituto Rope, uma organização sem fins lucrativos que realiza sonhos de pessoas em tratamento de doenças graves e em cuidados paliativos.

Além de produzir conteúdo para as redes sociais do instituto, busco constantemente aplicar na prática os conhecimentos adquiridos durante minha graduação em Análise e Desenvolvimento de Sistemas (ADS).

Com esse objetivo, desenvolvi esta Landing Page para facilitar o processo de doações via PIX, oferecendo uma experiência simples, intuitiva e acessível para os apoiadores da instituição.

Objetivo

Criar uma página de doação rápida e responsiva, permitindo que qualquer pessoa possa contribuir com o Instituto Rope de forma prática e segura.

O projeto foi desenvolvido utilizando tecnologias fundamentais do desenvolvimento web, servindo também como exercício prático dos conhecimentos adquiridos na graduação.

Funcionalidades Implementadas

- Exibição da chave PIX institucional.
- Botão para copiar a chave PIX automaticamente.
- Mensagem de confirmação informando:

```text
✅ Chave copiada com sucesso!
```

- Botão para contato via WhatsApp.
- Redirecionamento para uma conversa pré-preenchida informando que uma doação foi realizada.
- Layout responsivo para dispositivos móveis e computadores.
- Identidade visual alinhada à proposta institucional.

Próximas Melhorias

Funcionalidades planejadas para as próximas versões:

- Inclusão de QR Code PIX.
- Melhorias de acessibilidade.
- Integração com sistemas de monitoramento de acessos.
- Estatísticas de conversão de doações.
- Otimização para SEO.

Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript

Aprendizados

Este projeto me permitiu colocar em prática conceitos estudados durante a graduação em Análise e Desenvolvimento de Sistemas, especialmente relacionados a:

- Estruturação de páginas web.
- Estilização com CSS.
- Manipulação do DOM com JavaScript.
- Experiência do usuário (UX).
- Responsividade para diferentes dispositivos.

Além do aprendizado técnico, o projeto demonstra como a tecnologia pode ser utilizada para gerar impacto social positivo, facilitando a captação de recursos para uma instituição que transforma sonhos em realidade.
